# 光影助教 · 波动光学可视化与虚拟实验

当前版本：**v1.10.0**（2026-11-23），更新记录见 [CHANGELOG.md](CHANGELOG.md)。

面向大学学生的大学物理（波动光学）学习软件：

- **现象仿真**：杨氏双缝、单缝衍射、光栅衍射、牛顿环、马吕斯定律。用一句话提问，AI 会自动选实验、设参数、画出图样，再给出讲解和一道小测题。
- **虚拟实验**：按实验课的真实流程操作，记录数据后由 AI 助教批改。
  - 迈克尔逊干涉仪测 He-Ne 激光波长；选做钠光双线波长差；M₂ 没调正时看到弯曲、直线的等厚条纹
  - 牛顿环测平凸透镜曲率半径（读数显微镜），接触点有灰尘、可不对中测弦长；第二部分劈尖测细丝直径
  - 分光计测光栅常数：完整调节流程（目镜、望远镜调焦、各半调节、平行光管），自己读主刻度和 30 格游标
  - 光纤耦合与弯曲损耗（三维调整架耦合单模光纤，拟合弯曲损耗，选做测模场直径）
  - 马吕斯定律与波片（最小二乘拟合验证马吕斯定律，进阶鉴别 λ/4、λ/2 波片）
  - 半导体激光器与光电二极管特性（多温度 P-I 曲线求阈值、斜率效率和特征温度 T₀，测光电二极管响应度）
  - 激光光束半径、发散角与 M²（刀口法拟合误差函数，w² 对 z 二次拟合；进阶用透镜把束腰移到导轨上）
  - 光具座测凸透镜焦距（共轴调节、二次成像法、自准法正反两次；“光路图”视图和三维模型实时画出近轴光线，能看到会聚点、屏上的弥散斑和自准法经平面镜的回程）
  - 望远镜放大率与视场（目镜调焦、物镜调焦消视差；比较法、出瞳法测放大率，读视场边缘求视场角，进阶换目镜；讨论标尺在有限远时的修正）
- **处理我的数据**：把真实实验课上记录的原始数据录进来（可从 Excel / WPS 直接复制粘贴），9 个实验都支持。软件按与虚拟实验相同的方法计算——逐差法、最小二乘拟合、不确定度与规范结果——并自动检查常见问题（如中途反转鼓轮、数错环、游标读数抄错、基准漂移、测点分布不合理），再由 AI 助教批改、导出实验报告。实测数据与虚拟实验分开保存；“填入示例数据”生成的数据逐格记录来源（灰色斜体），没有全部换成自己的数据时，页面和报告都会注明“含示例数据”；信号无法分辨或结果不合物理时不给出正式结果。
- **让学生自己动脑**：
  - **我先算**：结果区先隐藏，学生用自己的数据算平均值、u<sub>A</sub>、u<sub>B</sub>、u 和规范结果，程序逐项核对并指出错在哪一步（逐差配组、√2、取位、末位对齐等），算对后才显示程序的结果。
  - **先预测、再观察**：每个虚拟实验开始记录前先做一道预测题，动手观察后再看解释。
  - **探究任务**：每个虚拟实验藏着一个真实的系统误差（回程差、接触点灰尘、度盘偏心、读数指标偏差、端面偏移、暗电流等），学生用自己的数据把它找出来并量化。
  - **教学设置**：A 类是否乘 t₀.₆₈₃ 因子、结果用 u 还是扩展不确定度 U = 2u、不确定度保留几位、只进不舍还是四舍五入、“我先算”可跳过 / 必须先算 / 不使用，按本校教材设置。
  - 实测数据会检查读数位数是否与仪器分度相符（如读数显微镜应估读到 0.001 mm、游标读到整数分）。
  - 这些过程都会写进实验报告的“自主计算与探究”一节。
- **一键导出实验报告**：每个虚拟实验页面底部都可以导出 Word 文档或网页（在浏览器里打印为 PDF），包含实验原理、步骤完成情况、数据表、计算结果与不确定度、拟合图、当前视场和 AI 评语；可填写姓名、学号、班级。报告保存在“文档/光影助教实验报告”文件夹，可以直接作为参赛支撑材料。
- **三维器材模型**：每个虚拟实验都有按真实仪器建模的三维模型，可以 360° 拖动查看、缩放、平移。模型随操作实时联动：转动鼓轮时动镜或显微镜会移动，转动望远镜时它会绕中心轴转动，迈克尔逊干涉仪的观察屏上显示实时的干涉图样，光纤绕上圆柱时弯曲处会发出泄漏的红光。

AI 使用 **DeepSeek**，API Key 只保存在你自己的电脑上。

## 一、生成软件（只需做一次）

电脑上需要安装 **Python 3.10～3.12**（Windows 安装时勾选 “Add python.exe to PATH”）。打包时要联网下载工具。

| 系统 | 操作 | 生成的软件 |
|---|---|---|
| Windows | 双击 `一键打包（Windows）.bat` | `dist\光影助教-v1.4.2.exe` |
| macOS | 双击 `一键打包（macOS）.command` | `dist/光影助教.app` |

打包大约需要 3～5 分钟，完成后会自动打开 `dist` 文件夹。版本号自动取自 `server.py` 的 `APP_VERSION`：Windows 的文件名带版本号，右键 → 属性 → 详细信息也能看到；macOS 在“显示简介”里能看到。不想自己打包，也可以直接在 GitHub 的 Releases 页面下载 Windows 版。之后**双击软件即可使用，不再需要 Python**。生成的 exe 也可以直接发给同学。

## 二、第一次打开

1. 第一次打开会自动弹出“设置”。
2. 在 <https://platform.deepseek.com> 充值少量余额，然后在 “API Keys” 页面创建一个 Key（以 `sk-` 开头）。
3. 把 Key 粘贴到设置里，点“保存并测试”。看到“连接成功”就可以用了。

不填 Key 也能用：讲解和批改会改用内置规则（右上角显示“未设置 API Key”）。

## 三、发给同学试用

- **同学自己填 Key**：直接把 exe 发过去，对方第一次打开时填自己的 Key。
- 发布版不再支持内置 API Key。个人配置、使用日志和实验存档不会进入安装包或 Git 仓库。

## 四、使用数据（写“应用成效”用）

每次提问、答题、调参、实验记录和 AI 批改都会记在本机：

- 软件里：**设置 → 使用数据**，可以看到汇总，并能打开数据文件夹。
- 数据文件位置：
  - Windows：`%APPDATA%\光影助教\usage_log.jsonl`

收集同学的数据时，请他们把这个文件发给你。

## 五、常见问题

- **解压后文件名是乱码**：请用 Windows 10/11 自带的解压、7-Zip 或 Bandizip 解压（本压缩包按国际标准使用 UTF-8 文件名）。
- **双击 bat 提示找不到 Python**：安装 Python 3.12，并勾选 “Add python.exe to PATH”。
- **安装时 pythonnet 报错**：一般是 Python 版本太新，换成 3.12 再试。
- **三维模型显示“这台电脑不支持三维显示”**：显卡驱动过旧或被禁用了硬件加速，更新显卡驱动即可；实验仍可用“示意图”完成。
- **Windows 打开后窗口空白**：电脑缺少 WebView2（Win10 早期版本才会遇到），到微软官网搜索 “WebView2 Runtime” 安装即可。
- **杀毒软件报毒**：PyInstaller 打包的单文件程序偶尔会被误报，选择“信任”或“允许运行”即可。
- **Mac 提示“无法验证开发者”**：在访达中右键点击软件 → 打开。
- **AI 报“余额不足”或“Key 无效”**：到 DeepSeek 后台检查余额，或在设置里重新填写 Key。

- **改 AI 的说话方式**：讲解的提示词在 `sim.js` 的 `buildPrompt`，批改的提示词在各个 `lab-*.js` 的 `review()` 里。
- **修改三维模型**：在 `models3d.js` 里，每个部件都是长方体、圆柱、回转体等基本形状拼成的，尺寸单位是厘米。
- **加一个虚拟实验**：照着 `lab-newton.js` 写一个新文件（提供 `mount / render / key`），在 `index.html` 里加标签按钮和容器，在 `app.js` 的 `LABS` 里注册。
- **改了界面上的文字后标题字体缺字**：标题字体只包含当前用到的汉字。新增的字会自动用系统宋体显示，不影响使用；如需补齐，用 fontTools 的 `pyftsubset` 从思源宋体 SemiBold（简体中文）重新生成 `fonts/serif-subset.woff`，`--text-file` 中包含原有字符和新增的标题文字。
- **给“处理我的数据”加一个实验或一项内容**：在 `mydata.js` 的 `SPECS` 里照现有实验写一项：`groups` 描述参数和数据列，`process()` 返回数据表、结果、问题清单和给 AI 的摘要；再在 `index.html` 的 `datatabs` 里加按钮和容器，并在 `server.py` 的 `LAB_NAMES` 里登记（实测数据的存档名为 `u` + 实验代号）。

## 七、仿真里的“真实误差”

虚拟实验里模拟了这些误差：测微螺杆的回程差、读数最后一位的估读误差、螺杆传动的比例误差、分光计刻度盘的偏心差，以及光栅不垂直、显微镜没对中、离焦、M₂ 残留倾角、接触点灰尘、分光计各项调节没到位、游标读错等误差；光纤实验还模拟了激光功率的缓慢起伏、绕线时碰动输入端造成的耦合变化，以及包层光；偏振实验模拟了转盘零点偏差、偏振片的有限消光比和波片相位延迟的制造误差；半导体激光器实验模拟了阈值附近的平滑弯折、高电流时的轻微饱和、TEC 的温度响应时间和光电二极管的暗电流。AI 批改时能拿到系统记录的对准偏差和鼓轮反转次数，所以能指出具体是哪一组数据、什么原因。

## 修复版说明（2026-11-14）

- 实验读数、仪器参考值与最近批改内容自动保存至数据目录下的 `lab_sessions.json`，下次启动恢复。清空会清除对应实验的当前存档。
- 导出报告时填写的姓名、学号、班级保存在数据目录下的 `report_who.json`，各实验共用；报告栏的“清除个人信息”可以删除。
- 修复实验切换后的讲解和小测不同步、连续请求覆盖、字符串答案误判，以及零角度差和重复环数产生无效计算的问题。
- 本地写入接口要求同源请求、JSON 和会话令牌；仅监听本机。
- 回归检查：`python -B tests/test_server.py` 和 `node tests/test_frontend.js`。测试使用临时数据与模拟 AI，不消耗额度。
